# 🧱 LEGO Code of Conduct

## Building Together - One Brick at a Time

Just like building with LEGO blocks, creating great software requires collaboration, precision, and respect for every piece that contributes to the whole. This Code of Conduct outlines our expectations for all those who participate in our community, as well as the consequences for unacceptable behavior.

## Our LEGO Principles

### 1. 🎯 Precision & Quality
- Focus on building solutions that snap together perfectly
- Provide constructive feedback that helps improve the build
- Take pride in your work and attention to detail

### 2. 🤝 Collaboration
- Every brick matters - respect all contributors regardless of experience level
- Share knowledge and help others build their skills
- Work together to create something greater than the sum of its parts

### 3. 🌈 Inclusivity
- Welcome builders of all backgrounds and skill levels
- Create an environment where everyone feels safe to contribute
- Celebrate diverse perspectives and approaches

### 4. 📐 Structure & Standards
- Follow the building instructions (contributing guidelines)
- Maintain consistent patterns and quality standards
- Document your work so others can understand and build upon it

## Expected Behavior

**DO** (Like Following Building Instructions):
- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Gracefully accept constructive criticism
- Focus on what is best for the community
- Show empathy towards other community members
- Help maintain a clean and organized codebase
- Provide clear, actionable feedback in code reviews
- Document your contributions thoroughly

**DON'T** (Like Mixing LEGO with Off-Brand Blocks):
- Use sexualized language or imagery
- Make trolling, insulting, or derogatory comments
- Engage in personal or political attacks
- Publish others' private information without permission
- Conduct yourself unprofessionally in any project space

## Scope

This Code of Conduct applies to all project spaces, including:
- GitHub repositories (issues, pull requests, discussions)
- Code reviews and comments
- Project documentation
- Community discussions
- Public spaces where you represent the project

## Enforcement

### Reporting

If you experience or witness unacceptable behavior, please report it by:
- Opening a private issue on GitHub
- Contacting the project maintainers directly
- Emailing support through our [GitHub Issues](https://github.com/BondIT-ApS/kubernetes-secret-generator/issues)

All complaints will be reviewed and investigated promptly and fairly.

### Consequences

Project maintainers will take appropriate action in response to violations:

1. **First Warning**: Private written warning with explanation
2. **Temporary Ban**: Temporary suspension from project interaction
3. **Permanent Ban**: Permanent removal from all project spaces

Serious violations (harassment, threats, discrimination) may result in immediate permanent ban.

## Building a Better Community

Remember: Just as every LEGO brick serves a purpose in the final creation, every community member contributes to our collective success. Let's build something amazing together!
